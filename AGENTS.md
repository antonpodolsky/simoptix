# SimOptix

SimOptix is a set of sim racing tools for capturing stabilized VR footage and overlays. `README.md`
describes the repo and its parts.

The instructions for coding agents are seven skills in `.agents\skills\`, each a `SKILL.md` in plain
Markdown:
- Before any work, read `.agents\skills\dev\SKILL.md` in full and follow it. It holds the rules for the
  whole repo and the order to work in.
- Before writing anything that is committed, pushed or posted, read
  `.agents\skills\public-text\SKILL.md`. It says what stays out of everything public: every file in
  the repo, commit messages, branch names, and all of GitHub.
- Before writing or changing a README, `CONTRIBUTING.md`, this file, a file of the skills or a pull
  request's Changelog lines, read `.agents\skills\docs\SKILL.md`.
- Before writing, changing or reviewing code, read `.agents\skills\code-style\SKILL.md` (how it looks) and
  `.agents\skills\code-practices\SKILL.md` (how it is built).
- Before writing a commit message, or opening or editing a pull request, read
  `.agents\skills\pull-requests\SKILL.md`.
- Before writing or editing an issue, or a comment on an issue or a pull request, read
  `.agents\skills\issues\SKILL.md`.

This file only points at the skills. Change the rules there.
