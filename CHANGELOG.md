# Changelog

This file lists what changed in each release of SimOptix, newest first. Each version links to its
release on GitHub.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the version numbers
follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html). While the version starts with 0, a
new minor version, such as 0.2.0, may also change how you set SimOptix up or what it needs.
